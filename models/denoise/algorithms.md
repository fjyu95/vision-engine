## 二、详细分类介绍

### 1. 传统滤波与变换方法

这类方法不依赖训练数据，计算效率高，适合快速处理或作为baseline。

| 算法                          | 原理           | 优点            | 局限        | 实现                                                       |
| --------------------------- | ------------ | ------------- | --------- | -------------------------------------------------------- |
| **高斯滤波**                    | 卷积核加权平均      | 平滑均匀          | 边缘模糊      | OpenCV `cv2.GaussianBlur`                                |
| **中值滤波**                    | 邻域中值替换       | 去除椒盐噪声优秀，保持边缘 | 对高斯噪声效果一般 | OpenCV `cv2.medianBlur`                                  |
| **双边滤波**                    | 空间+值域权重      | 保边平滑          | 计算量稍大     | OpenCV `cv2.bilateralFilter`                             |
| **Non-Local Means (NLM)**   | 利用非局部相似块加权平均 | 对纹理友好，细节保持好   | 参数敏感，速度较慢 | OpenCV `cv2.fastNlMeansDenoising*`                       |
| **Total Variation (TV) 去噪** | 最小化总变分约束     | 保边能力强，航空图像常用  | 可能出现过平滑   | scikit-image `denoise_tv_chambolle`/`denoise_tv_bregman` |
| **小波变换**                    | DWT分解 + 阈值去噪 | 多分辨率分析        | 阈值选择敏感    | PyWavelets库                                              |

### 2. 经典模型驱动方法

这些方法基于图像先验（稀疏性、非局部自相似性、低秩等），效果优于简单滤波。

| 算法        | 核心思想     | 性能参考(PSNR) | 适用场景         |
| --------- | -------- | ---------- | ------------ |
| **BM3D**  | 块匹配+协同滤波 | \~30-35dB  | 高斯噪声，传统方法天花板 |
| **WNNM**  | 加权核范数最小化 | \~32-33dB  | 遥感图像，保持边缘    |
| **K-SVD** | 稀疏字典学习   | \~33-35dB  | 遥感图像         |

**安装BM3D**：

```bash
pip install bm3d
```

### 3. 深度学习方法（通用图像）

深度学习方法在去噪质量上显著超越传统方法，适合对质量要求高的场景。

| 算法         | 年份   | 特点           | PSNR(BSD68, σ=25) | 代码        |
| ---------- | ---- | ------------ | ----------------- | --------- |
| **DnCNN**  | 2017 | 残差学习+BN，经典基线 | \~31.7dB          | \[官方]     |
| **FFDNet** | 2018 | 可调噪声水平，快速    | \~31.8dB          | \[官方]     |
| **SCUNet** | 2023 | CVPR，自校准卷积   | \~33.0dB          | \[GitHub] |

### 4. 混合去噪框架

结合传统方法和深度学习优势，针对混合噪声（高斯+椒盐）优化。

**2025年混合框架**（IOPscience）：

```
输入噪声图像 → CLAHE增强 → MDBUTMF去除椒盐 → GCF几何保持 → DnCNN恢复纹理 → 输出
```

- **CLAHE**：对比度受限自适应直方图均衡，增强阴影/过曝区域
- **MDBUTMF**：改进决策型非对称修剪中值滤波，抑制椒盐噪声
- **GCF**：高斯曲率滤波，保持几何结构
- **AMOA**：自适应蜉蝣优化算法，动态调整参数
- **性能**：PSNR 32.80dB，SSIM 0.888（混合噪声下）
